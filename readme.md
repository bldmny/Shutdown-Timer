Shutdown Timer

A lightweight Windows utility for scheduling automatic shutdowns.

Features
Schedule shutdowns using seconds, minutes, hours, or days
Multiple input formats supported
Cancel active shutdown timers
Simple and lightweight
No installation required
Examples
30s
45m
3h
2d

10 minutes
2 hours
1 day
Commands
cancel
close
Running

Run the application as Administrator if scheduling or cancelling shutdowns does not work.
